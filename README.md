# Currency Converter

Консольный конвертер валют на Python.

## Описание

Проект позволяет:
- конвертировать валюту;
- смотреть курс валют;
- сохранять историю операций;
- рассчитывать комиссию за конвертацию.

## Используемые технологии

- Python 3
- ООП
- Классы
- Работа со словарями
- Обработка ошибок
