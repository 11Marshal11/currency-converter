# Currency Converter

Консольный конвертер валют на Python.

## Описание

Проект позволяет:
- конвертировать валюту;
- смотреть курс валют;
- сохранять историю операций;
- рассчитывать комиссию за конвертацию.

## Используемые технологии

- Python 3
- ООП
- Классы
- Работа со словарями
- Обработка ошибок

## Как запустить проект

1. Склонировать репозиторий:

```bash
git clone https://github.com/danilbelovodsky-bot/currency-converter.git
```

2.Перейти в папку проекта:
```
cd currency-converter
```

3. Запустить файл:
```
python ConverterEngine.py
```
Основные классы:
###ExchangeRateBoard
Хранит курсы валют и позволяет получить курс по коду валюты.

###HistoryManager
Хранит историю операций конвертации.

###Transaction
Описывает одну операцию конвертации.

###ConverterEngine
Выполняет саму конвертацию валют и добавляет запись в историю.
